# RaceDay System

## Description
The RaceDay system is a platform designed to allow organizers to create running events, and participants to browse, enroll, and view results.

## Roles
1. **Organizer**: Can create, update, and manage events, as well as input final race results.
2. **Participant**: Can browse events, enroll in races, and view their own results.
